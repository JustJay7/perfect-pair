Where do I find the workshop credentials?

Return to the workshop event dashboard where you opened the AWS console. Under AWS account access, choose Get AWS CLI credentials (sometimes called Get AWS Credentials). Copy the values for AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY, and AWS_SESSION_TOKEN into the matching fields below. Copy only the values, without the export commands or surrounding quotes. Refresh all three together when the session expires.

Use the exact profile approved by the organizers. All three credential fields are required for a workshop session. Leave all three blank to use credentials already configured locally.
